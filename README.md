# Spotify TV Mod (TizenBrew)

Modulo [TizenBrew](https://github.com/reisxd/TizenBrew) che apre il web player di Spotify sulle TV Samsung Tizen:

- user agent Chrome desktop (Spotify blocca il browser della TV)
- navigazione con il telecomando: frecce, OK, Indietro, tasti play/pausa/traccia
- pannello diagnostica (tasto BLU), ricarica (tasto GIALLO)

## Installazione

In TizenBrew → Module Manager → aggiungi il modulo `gh/<utente>/spotify-tizenbrew`.

Requisiti: TV con Widevine (verificato su Tizen 8.0 / 2024).
